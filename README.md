# Lumina-Overview
Lumina — Social Media Mobile Platform

Lumina is a pre-launch, pre-revenue social media mobile application available for acquisition.

Project Overview

Lumina is built using modern mobile and backend technologies.

Technology Stack

- Mobile: React Native, Expo, TypeScript
- Backend: Python, FastAPI
- Database: MongoDB

Key Features

- User profiles
- Social feeds
- Follow and unfollow
- Like and save posts
- Search and explore
- Photo and video sharing
- Stories and short-form video interfaces
- Moderation and reporting features

Feature availability should be confirmed during a technical review.
